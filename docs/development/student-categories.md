# Student categories and public profiles

Students can optionally publish a professional summary and general location. Discoverability is off by default. The public category directory displays only opted-in profiles and their category rating from completed task reviews. It excludes NIC, phone, private address, and identity documents.

Task Posters browse these profiles at `/dashboard/student-categories` and can send private offers. The former `/dashboard/student-lookup` URL redirects there. The old AI lookup endpoint has been removed. Gemini remains available for task title and description enhancement via `GEMINI_API_KEY`.

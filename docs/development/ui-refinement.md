# UniWorkSL neutral multicolor refinement

The shared light theme now uses white/off-white backgrounds and neutral gray borders; dark mode uses near-black and charcoal surfaces. Violet is the general interaction accent, while terracotta, slate blue, tan, green, sage, and sunflower remain limited to semantic details, badges, category marks, and illustrations. Status colors retain their established meanings.

The public landing hero is intentionally preserved. Below it, categories use varied muted icon colors, Task Poster content uses neutral surfaces, and the footer receives larger navigation and supporting type. The public header wordmark uses a single reduced-motion-aware gradient sweep; its icon and dashboard/mobile wordmarks stay neutral. Mobile semantic theme tokens match the achromatic palette.

`UI_DESIGN_SYSTEM.md` is intentionally unchanged under the repository's contributor instruction to keep that file immutable. No API, authentication, task lifecycle, or backend behavior was changed.

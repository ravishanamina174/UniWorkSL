# SafeTask V1 implementation notes

SafeTask is optional. A student requests a start code, chooses to generate a guardian link or skip, and then verifies the existing PIN. The backend creates a token from 32 random bytes and stores only its SHA-256 hash. A pending link cannot receive location updates. Only the assigned student can update or revoke a session. Guardian requests are public only with the valid token. Expired and revoked requests return 404 without location. The backend derives expiry from `task_executions.completed_at + 1 hour` on every request; device clocks do not extend it.

The app currently uploads a location when the task screen is active and then approximately every four minutes while that screen remains mounted. This is a foreground fallback, **not locked-screen or background tracking**. The Android development build and scoped background authentication work remain to be completed before this feature can be described as background tracking. If GPS permission is denied, no location is sent. The task arrival check remains separate. Stop Sharing revokes access and clears the saved position.

The guardian page uses Leaflet and Stadia Maps Alidade Smooth raster tiles by default. For a deployed site, create a Stadia Maps account, confirm the pilot qualifies for its current plan, register the web origin in Stadia's domain authentication settings, and set `NEXT_PUBLIC_SAFETASK_TILE_URL=https://tiles.stadiamaps.com/tiles/alidade_smooth/{z}/{x}/{y}{r}.png` in Vercel. If using a different licensed provider, set its template URL and update the Leaflet attribution. The web page sends only its origin as a referrer to the tile provider; the private guardian token remains in the page path and is never sent to tiles. Guardian API fetches send no referrer. A tile failure hides the map and leaves coordinates and the external Google Maps link available. Existing ignored `apps/web/.env.local` values are not automatically changed: replace an old `tile.openstreetmap.org` value manually for local tests. The public OSM tile endpoint requires a valid Referer and compliance with its usage policy, and is unsuitable as an unregistered production fallback. Set `EXPO_PUBLIC_WEB_BASE_URL` to the deployed HTTPS web origin before generating real links; `EXPO_PUBLIC_API_BASE_URL` must point to the deployed API. Apply Flyway V9 before enabling the API. A daily cleanup removes expired completed sessions after 24 hours, revoked sessions after 24 hours, and unused pending sessions after 24 hours. The guardian page is explicitly non-indexed and requests disable caching.

Real Android verification: install a development build, start an accepted task, generate and copy a link, open it in another browser, verify the PIN, leave the task screen open, and inspect location freshness. Complete the task and test both safety prompt choices. For the full one-hour window, verify the guardian endpoint returns 404 after the server deadline. Locked-screen updates require further implementation and device testing.
